claude-desk

A native Mac front-end for the Claude CLI.

If you already run claude in the terminal, claude-desk puts a real Mac window around it — per-project sessions, multi-pane chat, MCP permission prompts in a proper dialog instead of a TTY line, image paste, and rendered markdown.

Local-only. Sessions are saved on your Mac. The only network call the app makes is the one the Claude CLI was going to make anyway, on your behalf.

What it does

📁
Per-project sessions Each project is a directory on your Mac. Switch between them in the sidebar; each carries its own conversation history. New projects land in ~/claude-desk/Projects/, but you can attach any existing directory.
🗂
Multi-pane chat Cmd-click a second project in the sidebar to open them side-by-side. Drag the divider to rebalance; the split persists across launches.
🔐
MCP permission prompts as dialogs Instead of typing y/n into a terminal, MCP tool calls pop a real macOS confirmation dialog. Tool arguments are formatted readably, not splatted as raw JSON.
📷
Paste screenshots into the chat Cmd-Shift-4, then Cmd-V into the input. The image attaches inline and is sent on submit. No file picker round-trip.
📜
Rendered markdown, streaming output Code blocks, lists, and tables render as you'd expect. Tokens stream in as Claude writes, so you can stop a generation early or read along.

How it works

claude-desk doesn't talk to Anthropic directly. It shells out to the Claude CLI binary you already have installed and renders the JSON stream into a chat UI. Your existing Claude CLI authentication (Anthropic API key or claude.ai session) is what authenticates each request — claude-desk never sees your credentials.

Practical upshot: any feature, model, or MCP server that the CLI supports works in claude-desk automatically. It also means you need the CLI installed. Follow the install steps at docs.claude.com.

What it doesn't do

  • No bundled CLI. Bring your own claude binary. We don't want to be on the upgrade path between you and Anthropic's releases.
  • No subscription, no telemetry, no account. The app itself doesn't talk to any server the developer operates.
  • No cloud sync. Sessions live in ~/Library/Application Support/claude-desk/. Back them up however you back up the rest of your Mac.

Requirements

  • macOS Ventura 13.0 or later (Apple Silicon or Intel)
  • The claude CLI installed and authenticated
