Frequently asked questions

I get "claude: command not found" when I send a message.

claude-desk shells out to the claude CLI binary. Install it first — follow the steps at docs.claude.com, then run claude --version in Terminal to confirm. If it works in Terminal but not in claude-desk, the app may not see your shell PATH; quitting and relaunching usually fixes it.

Where are my sessions stored?

On your Mac, in ~/Library/Application Support/claude-desk/. Each project has its own .jsonl transcript file under sessions/. They're plain text — feel free to back them up, grep them, or delete them.

Where do new projects get created?

By default, under ~/claude-desk/Projects/. The New Project… command (Cmd-N) creates a fresh directory there. Open Project… (Cmd-O) lets you attach any existing directory on your Mac as a project — useful for hooking claude-desk into an existing repo.

How do I open two projects side-by-side?

Cmd-click a second project in the sidebar. Both panes load. Drag the divider between them to resize; the split width persists across launches per pair.

The CLI is asking me to confirm a tool call but no dialog appeared.

The dialog window is brought to the foreground via NSApp.activate, which sometimes gets suppressed if the app isn't the active app. Click the claude-desk dock icon to bring it forward, and the dialog should appear. If it still doesn't, email me with the model and CLI versions.

Can I paste screenshots into the input?

Yes. Take a screenshot (Cmd-Shift-4 → area, or Cmd-Shift-3 → fullscreen), then click into the chat input and Cmd-V. The image attaches inline and gets sent on submit. You can also paste images that you've copied from another app.

Does this work without an internet connection?

The app itself runs offline — you can open it, browse past sessions, and edit settings. But sending a message calls the Claude CLI, which needs network access to reach Anthropic.

Does this run on macOS 12 (Monterey) or earlier?

No. claude-desk requires macOS Ventura 13.0 or later.

Is the source code open?

Not currently. May open-source later — drop me an email if that matters to you.

Reporting a bug

Email liucxer@gmail.com with:

  1. What you did (one or two sentences)
  2. What you expected to happen
  3. What actually happened
  4. macOS version (Apple menu → About This Mac)
  5. claude-desk version
  6. claude --version output
  7. (Optional) A screenshot or the relevant lines from the session transcript at ~/Library/Application Support/claude-desk/sessions/<project-id>.jsonl
