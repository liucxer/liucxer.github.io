常见问题

怎么开始一道题?

在主页点封面进入卡片列表,左右滑动切换卡片。每张卡片就是一道独立的推理题。

怎么切换到下一张卡?

在卡片上向左滑动 → 下一张。向右滑动 → 上一张。

星星是怎么得到的?

每答对一题就会获得一颗星星,难度高的题多发几颗。会话结束页会显示这次得了多少。

能切换孩子吗 / 重置进度吗?

这一版没有"账号"或"进度"的概念 —— 关掉 app 重新打开就是新的一次。我们更希望这是个轻量的陪伴工具,而不是任务系统。

app 有声音吗?

没有。这个 app 设计上就是"家长读 + 孩子答"。所以不会被音效打断对话,也不会成为孩子要的"再来一次"的奖励噪音。

支持 iPad 吗?

支持。在 iPad 上字号、留白、行宽都会变大,适合两个人一起看一台设备。

iOS 13 / 12 能用吗?

不能。最低需要 iOS / iPadOS 14.0,因为部分 SwiftUI API 是从 14.0 才有的。

会不会出 Android 版?

暂时没有计划。app 是用 SwiftUI 写的,跨平台代价较高。

反馈 Bug

发邮件到 liucxer@gmail.com,告诉我:

  1. 你做了什么(一两句话)
  2. 你期望发生什么
  3. 实际发生了什么
  4. iOS 版本(设置 → 通用 → 关于本机)
  5. 设备型号
  6. (可选)截图或屏幕录像
